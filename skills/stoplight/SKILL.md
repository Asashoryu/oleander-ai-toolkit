# Stoplight

A method for understanding a source, not for memorising it. It does not depend on the subject: where and how to write comes from the topic's setup note.

Start by reading `<Topic> - Setup`. If it does not exist, run `studio-setup` first. Follow its global rules (explain first, short answers, open points, batch writing).

## Claim types

| Type | Colour | Meaning |
|---|---|---|
| **Fact (F)** | green | The source strongly supports it. Carries a citation with its exact place, for a book the edition and page or standard numbering. |
| **Interpretation (I)** | yellow | The user's reworking of a fact. |
| **Supposition (S)** | red | Strong for the user, weak in the source. Includes missing links the source does not state. |

The type belongs to the claim, not to what it derives from: any type can derive from any type. A fact stays a fact while it has its citation.

## Reasonings

A reasoning (R) connects one or more premises to a new claim of any type: `R1. F1 + F2 → I1: how we get from the premises to the conclusion`. A claim may have no premises. Claims are numbered once for the whole report: F1, F2…, I1…, S1…, R1….

## Claims are short

One sentence, as short as possible. The citation is only the fragment that holds the claim. Never invent a source or a quote: if you cannot verify one, say so and do not mark it as a fact.

## A session

1. Read the setup note and the existing report.
2. Say in one line which subject the session covers. If the source has a structure (chapters), the report follows it: claims go in the section they belong to, and a reasoning goes in the section of its conclusion.
3. **Explain**, short and sourced. The user asks, you answer. Do not quiz. Point out where the source says something and where you are reconstructing.
4. If the user objects, discuss. An objection is not a claim: it becomes one only when the user makes it theirs.
5. Show `Aperto: …` for unresolved points. When none remain, or the user says to go on, the subject is closed.
6. **Write the batch.** Propose all the claims and reasonings that came out of the discussion, each with type, wording and citation. The user confirms, corrects or discards line by line. Then write them as the setup says (with a drawing per section only if the setup asks for it) and update the report.
7. A new claim that contradicts an existing one: stop and show both, ask how to resolve, never decide alone.

Nothing is added to the report before the user has agreed on the subject.

## Import

To work from a conversation exported from another chat, use the source note that `studio-setup` produced from it, and proceed as above.
